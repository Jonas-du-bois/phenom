## 🎯 Fonctionnalités Principales

### Pour les Utilisateurs
- 📸 **Créer des observations** de phénomènes naturels
- 🗺️ **Carte interactive** pour visualiser les observations
- 💬 **Commenter** et échanger avec la communauté
- 👤 **Profil personnalisé** avec historique

### Pour les Développeurs
- 🔒 **API REST sécurisée** avec JWT
- 📊 **Base MongoDB** avec indexation géospatiale
- ✅ **Tests automatisés** avec Jest
- 📝 **Documentation Swagger** interactive
- 🐳 **Docker ready** pour déploiement facile

## 🛠️ Stack Technique

### Backend
```
Node.js 18+ | Express.js | MongoDB | Mongoose | JWT | Jest
```

### Frontend
```
Vue.js 3 | Vite | Tailwind CSS | Leaflet | Pinia | Vue Router
```

### DevOps
```
Docker | Docker Compose | Nginx | GitHub Actions
```

Nous accueillons toutes les contributions ! Consultez le [Workflow Git](guides/git-workflow) pour les conventions.

1. **Fork** le projet
2. **Clone** votre fork localement
3. **Créer une branche** pour votre feature

5. **Push** et créer une **Pull Request**
